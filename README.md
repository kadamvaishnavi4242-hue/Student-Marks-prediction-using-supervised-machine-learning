# Student Marks Prediction using Machine Learning

## Project Overview
This is a supervised machine learning mini project that predicts student marks
based on the number of hours studied.

## Dataset
The dataset consists of study hours and corresponding marks of 6 students.

## Model Used
- Linear Regression

## Evaluation Metrics
The model performance is evaluated using:
- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Output
After running the code, the following results are obtained:

Predicted Marks for 2 hours of study: 57.97

Mean Squared Error (MSE): 0.628571 
Mean Absolute Error (MAE): 0.66666
Root Mean Squared Error (RMSE): 0.79  

## Files in this Repository
- supervised machine learning.py : Contains the complete Python code for training and testing the model
- README.md : Project explanation and output

## Conclusion
This project demonstrates how machine learning can be used to predict student
performance using simple regression techniques.
